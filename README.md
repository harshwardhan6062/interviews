# interviews

Interview preparation, kept as one place: what gets asked, how I answer it, and
the mental models the answers come from.

Companion to the build work in [`pinakes`](https://github.com/harshwardhan6062/pinakes)
(agentic AI, built increment by increment) and the notes in
[`system-design`](https://github.com/harshwardhan6062/system-design) (DDIA).
Where those two are the *doing*, this is the *saying* — the same material
compressed to what survives a 45-minute room.

## Layout

```
agentic-ai/     the eight mental models, and the questions each one generates
system-design/  HLD + LLD patterns, cross-questions, and how to sequence an answer
dsa/            Amazon-shaped problems and the patterns underneath the story
behavioural/    Leadership Principles, STAR stories, the war stories worth telling
```

## How this is meant to be used

- **Models over answers.** A memorised answer dies on the first follow-up. Each
  section leads with the model that generates answers on demand.
- **Real numbers.** Where a claim has a measurement behind it — from the build
  repos — it's cited, because "hybrid beat dense 0.91 to 0.82 on my own corpus"
  beats reciting that hybrid is better.
- **The honest gaps.** What's read vs built is marked, so nothing gets oversold
  in a room.
